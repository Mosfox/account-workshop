# ระบบจัดการสมาชิก (Account Workshop)

โปรเจกต์เว็บแอปพลิเคชันสำหรับจัดการสมาชิก พัฒนาด้วย Node.js, Express.js และ MongoDB ผู้ใช้สามารถสมัครสมาชิก เข้าสู่ระบบ ดูรายชื่อสมาชิก และลบบัญชีสมาชิกได้

## เทคโนโลยีที่ใช้

- **Node.js** — รัน JavaScript ฝั่งเซิร์ฟเวอร์
- **Express.js** — สร้างเว็บเซิร์ฟเวอร์และ REST API
- **MongoDB** — จัดเก็บข้อมูลสมาชิก
- **MongoDB Compass** — ใช้ดูและจัดการข้อมูลในฐานข้อมูล
- **bcryptjs** — แฮชรหัสผ่านก่อนจัดเก็บ
- **HTML, CSS, JavaScript** — พัฒนาส่วนติดต่อผู้ใช้

## ความต้องการของระบบ

- ติดตั้ง Node.js และ npm
- ติดตั้ง MongoDB Community Server
- ติดตั้ง MongoDB Compass (ไม่บังคับ แต่แนะนำสำหรับตรวจสอบข้อมูล)
- ใช้ Visual Studio Code สำหรับแก้ไขและรันโปรเจกต์

## การติดตั้ง

### 1. ติดตั้ง Dependencies

เปิด Terminal ใน VS Code แล้วเข้าไปยังโฟลเดอร์โปรเจกต์ จากนั้นรันคำสั่ง

```bash
npm install
```

### 2. เปิดใช้งาน MongoDB

ตรวจสอบว่า MongoDB Server กำลังทำงานอยู่ และใช้ Connection String ดังนี้

```text
mongodb://127.0.0.1:27017
```

โปรเจกต์ใช้ฐานข้อมูล `account-db` และคอลเลกชัน `users`

### 3. ทดสอบการเชื่อมต่อฐานข้อมูล

```bash
npm run test:db
```

หากเชื่อมต่อสำเร็จ ควรเห็นข้อความยืนยันการเชื่อมต่อ MongoDB ใน Terminal

### 4. เริ่มต้นเซิร์ฟเวอร์

```bash
npm start
```

เมื่อเซิร์ฟเวอร์เริ่มทำงานแล้ว ให้เปิดเว็บเบราว์เซอร์ไปที่

http://localhost:3000

หากต้องการหยุดเซิร์ฟเวอร์ ให้กด `Ctrl + C` ใน Terminal

## ความสามารถของระบบ

1. สมัครสมาชิกด้วย username, ชื่อ-นามสกุล, email และ password
2. ตรวจสอบข้อมูลที่จำเป็นก่อนสมัครสมาชิก
3. แฮชรหัสผ่านด้วย bcryptjs ก่อนจัดเก็บในฐานข้อมูล
4. เข้าสู่ระบบด้วย username และ password
5. แสดงรายชื่อสมาชิกจาก MongoDB
6. ลบบัญชีสมาชิกผ่าน API
7. แสดงหรือซ่อนรหัสผ่านขณะกรอกข้อมูล
8. ตรวจสอบและจัดการข้อมูลสมาชิกผ่าน MongoDB Compass
9. กำหนด role ของสมาชิก เช่น `member` และ `admin` สำหรับการทดลอง

## API Endpoints

| Method | Endpoint | รายละเอียด |
|---|---|---|
| POST | `/api/register` | สมัครสมาชิก |
| POST | `/api/login` | เข้าสู่ระบบ |
| GET | `/api/users` | ดูรายชื่อสมาชิก |
| DELETE | `/api/users/:username` | ลบบัญชีสมาชิก |

## การจัดเก็บข้อมูล

ฐานข้อมูลที่ใช้คือ `account-db` โดยเก็บข้อมูลสมาชิกในคอลเลกชัน `users`

ข้อมูลสมาชิกอาจประกอบด้วยฟิลด์ต่อไปนี้

- `username` — ชื่อผู้ใช้
- `name` — ชื่อ-นามสกุล
- `email` — อีเมล
- `passwordHash` — ค่าแฮชของรหัสผ่าน
- `role` — สิทธิ์ของผู้ใช้
- `loginCount` — จำนวนครั้งที่เข้าสู่ระบบ หากมีการบันทึกจากเซิร์ฟเวอร์
- `lastLoginAt` — เวลาที่เข้าสู่ระบบล่าสุด หากมีการบันทึกจากเซิร์ฟเวอร์

ระบบสามารถกำหนด Unique Index ให้กับ `username` และ `email` เพื่อป้องกันข้อมูลซ้ำกัน

## การตรวจสอบข้อมูลด้วย MongoDB Compass

1. เปิด MongoDB Compass
2. เชื่อมต่อด้วย `mongodb://127.0.0.1:27017`
3. เปิดฐานข้อมูล `account-db`
4. เลือกคอลเลกชัน `users`
5. ตรวจสอบข้อมูลสมาชิกในแท็บ Documents
6. ตรวจสอบดัชนีในแท็บ Indexes

## การทดสอบข้อมูลถาวร

1. สมัครสมาชิกและเข้าสู่ระบบอย่างน้อยหนึ่งบัญชี
2. หยุดเซิร์ฟเวอร์ด้วย `Ctrl + C`
3. รัน `npm start` ใหม่
4. เปิดเว็บที่ `http://localhost:3000`
5. ตรวจสอบว่าข้อมูลสมาชิกยังอยู่และเข้าสู่ระบบด้วยรหัสผ่านเดิมได้

ข้อมูลยังคงอยู่หลังรีสตาร์ตเซิร์ฟเวอร์ เนื่องจากถูกจัดเก็บใน MongoDB ไม่ใช่เก็บไว้เฉพาะในหน่วยความจำของ Node.js

## ข้อควรระวังด้านความปลอดภัย

- ต้องตรวจสอบข้อมูลทั้งฝั่งหน้าเว็บและฝั่งเซิร์ฟเวอร์
- ห้ามจัดเก็บรหัสผ่านจริงในฐานข้อมูล ให้จัดเก็บเป็น `passwordHash`
- การเปลี่ยนรหัสผ่านควรตรวจสอบรหัสผ่านเดิมและสร้างแฮชใหม่ด้วย bcrypt
- ระบบที่ใช้งานจริงควรมีระบบ Authentication และ Authorization
- ต้องตรวจสอบสิทธิ์ฝั่งเซิร์ฟเวอร์ก่อนอนุญาตให้ลบบัญชีหรือเปลี่ยน role
- ไม่ควรเปิดให้ผู้ใช้ทั่วไปแก้ไขสิทธิ์เป็น `admin` ได้เอง
- ควรสำรองข้อมูลก่อนทดลองลบหรือแก้ไขข้อมูลจำนวนมาก
